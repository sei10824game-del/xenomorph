# Xenomorph source research (Xenopedia / avp.fandom.com, fetched via its MediaWiki API)

Compared the mod's castes against the wiki. **Wiki-backed** = description matches a published source; **fixed** = was my own guess, corrected to the source; **no source found** = still an invention.

| Caste | Source finding (summary) | Status |
|---|---|---|

| Brute | USS Capella; colossal (Queen-Mother class); smooth round crest *without* hood; pauldron shoulders with back-curving spike; 4 crooked dorsal spines; long scythe-blade tail; arms longer than legs, semi-quadrupedal | fixed (scale 2.6, round crest, pauldrons, long arms, blade tail) |

## Not yet implemented (Xenopedia "Xenomorph variants" category, 149 pages, checked against the mod)

- Bursters: Bellyburster, Bloodburster, Goreburster, Bodyburster, Giant Chestburster, Multiburster

## Mutant lineage (Mutant Monsters / Mutant More)

Source for Mutant Monsters (Fuzss, 1.20.1 branch): the public mob classes (MutantZombie / Skeleton / Creeper / Enderman / SnowGolem) were read for attack timings, damage and effects. Mutant More: the source is not public, so abilities are inferred from the Modrinth description and the 2.0.0 changelog (item / entity / effect names). Treat those seven as interpretations.

| Xeno | Original | Ported abilities |
|---|---|---|
| Hulk | Mutant Zombie | seismic slam line, throw + dive, roar (12 blocks, raises drones) |
| Bone | Mutant Skeleton | tipped arrow, 6-arrow backflip barrage, rib crush |
| Blast | Mutant Creeper | 4-blast chain, lightning heal, charge by lightning, minions (+ tamed Minion Egg) |
| Void | Mutant Enderman | blink-dodge, tele-smash, scream (20 blocks), clones, block throw |
| Frost | Mutant Snow Golem | ice block throw, fire weakness, freeze immunity |
| Wither | Mutant Wither Skeleton | wither slash, wither bomb, blade flurry |
| Blaze | Mutant Blaze | 3 shield layers, fire volley, flame cone |
| Shulker | Mutant Shulker | homing bullets, shell guard + levitation burst |
| Husk | Mutant Husk | quicksand, sand boulder, roar |
| Hoglin | Mutant Hoglin | charge, gore, enrage after rapid hits |
| Frozen | Mutant Frozen Zombie | icicle volley, freeze-then-smash, snowballs |
| Jungle | Mutant Jungle Zombie | vine pull, thorn patch, gust, raise drones |

Not ported: item/mutation systems (laboratories, Formula Y/Compound Z), Spider Pig, Mutant Phantom (WIP upstream), Endersoul block carrying, Snow Golem water-ice platforms, zombie resurrection proper (replaced by drones from the ground).


## Fifth pass added
Host-derived: Gorilla, Rhino, Crocodile, Scorpion, Snake, Mantis, Saurian, Lion-worm, Jockey. Aquatic: Dolphin, Shark, Beluga, Swimming. Bursters: Giant Chestburster, Multiburster, Bodyburster, Queen-Burster; Abomination; Larva and Earth Xenomorph (Alien: Earth); Necromorph and Terminator crossovers; Octo- and Flying Facehuggers. Spider Pig and the Derelict Laboratory (Mutant More / Mutant Monsters). Voices: seven synthesized families.
Still not built: Mutant Phantom (WIP upstream), Xenoborg/Tarkatan/Drukathi/Vurfur/Condra-Morth/Ani-Men/Killer Croc crossovers, Octo-/Flying Facehugger hive generation (they only hatch rarely from eggs), proper swimming animations (aquatic castes reuse the quadruped pose).
